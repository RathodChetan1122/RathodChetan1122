## 🚀 Featured Engineering Projects

### 🚘 Smart Traffic Monitoring System using ANPR and ATCC
* **Problem Solved**: High-latency vehicular tracking and manual traffic flow auditing at critical metropolitan junctions.
* **Engineered Solution**: Devised a production-ready edge computer vision pipeline integrating **Automatic Number Plate Recognition (ANPR)** and **Automatic Traffic Counter and Classifier (ATCC)**. Leveraged Deep Learning inference workflows to read non-standard registration configurations under variable lighting constraints.
* **Technologies**: `Python`, `OpenCV`, `YOLO`, `PyTorch`, `Flask`, `PostgreSQL`
* **Key Impact**: Decreased inference latency across real-time feeds and established data pipelines feeding actionable traffic metrics back into central routing hubs.
* **Links**: [Production Repository](https://github.com/RathodChetan1122) • [System Architecture Architecture Demo](https://github.com/RathodChetan1122)

### 📋 Insurance Claim Management System
* **Problem Solved**: Fragmented documentation workflows, fraud susceptibility, and long processing lifecycles within commercial claim networks.
* **Engineered Solution**: Architected and executed a high-throughput enterprise **MERN Stack application** allowing secure claimant processing. Integrated granular RBAC (Role-Based Access Control) to separate administrative assessors from corporate clients.
* **Technologies**: `MongoDB`, `Express.js`, `React.js`, `Node.js`, `JWT`, `Tailwind CSS`
* **Key Impact**: Eliminated process silos with unified data ingestion and real-time validation layers, greatly optimizing the claim handling operational lifecycle.
* **Links**: [Source Code](https://github.com/RathodChetan1122) • [Live Deployment](https://github.com/RathodChetan1122)

### 🗓️ Smart Faculty Timetable Automation System
* **Problem Solved**: Algorithmic resource conflicts, redundant multi-department constraint handling, and manual overhead during academic scheduling.
* **Engineered Solution**: Engineered an analytical backend mapping complex scheduling metrics (faculty availability, room capacities, specialization prerequisites) using automated programmatic sorting rules and constraint satisfaction logic.
* **Technologies**: `Node.js`, `React.js`, `Express.js`, `MySQL`, `Algorithms`
* **Key Impact**: Completely abstracted scheduling conflicts out of the pipeline, providing multi-department synchronization in under a minute via a responsive admin dashboard.
* **Links**: [Source Code](https://github.com/RathodChetan1122) • [Design Mockup](https://github.com/RathodChetan1122)

### 🛡️ Real-Time SMS Spam Detection & URL Classification Engine
* **Problem Solved**: Phishing growth and high computational requirements for real-time edge security filters on messaging frameworks.
* **Engineered Solution**: Created a decoupled dual-model engine featuring a lightweight text feature extraction layer matching asynchronous malicious URL signatures using multi-stage classifications.
* **Technologies**: `Python`, `Scikit-learn`, `NLP`, `Flask API`, `JavaScript`
